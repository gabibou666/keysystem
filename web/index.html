GOOD TO KNOW

Before you publish.

More detail in the documentation.

How do I create a developer account?

Choose Create account and an available sign-in method: Google, Discord or email. Verify your address if you use email. Use the same sign-in method when returning to your workspace.

Can other developers access my projects?

Developer dashboard requests are restricted to the signed-in project owner. Keys are validated within a specific project.

How does monetization work?

Connect your own provider account in the Checkpoints tab and share your project key page. A completed, verified session grants a key with the project duration. Provider accounts, advertising and payouts are managed by the provider.

What happens when I publish an update?

The new source replaces the current published version of that project. Its loader URL stays the same. Users receive the new version the next time they load with a valid license; code already running is not updated automatically.

Do I need checkpoints to distribute my script?

No. Issue licenses directly from your dashboard or backend API. Checkpoints are an optional way for users to obtain a project key.

Can I recover a key after closing the result?

Manually issued keys are shown once. Copy or download them before closing the result. The dashboard retains a prefix and the license settings for management, rather than the full key.

Are uploaded scripts obfuscated?

No. Uploaded scripts are encrypted at rest and delivered after validation. Obfuscate your code before uploading if you need that additional protection.

How do my users get access?

Your users need a project license and your loader. You can issue keys directly or let them earn one through your project key page. They do not need a developer account.
